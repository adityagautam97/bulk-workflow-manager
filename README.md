# Bulk Workflow Manager

A side panel extension for the Sitecore Pages editor that displays a navigable content tree with multi-select checkboxes, allowing authors to select multiple items across different levels of the hierarchy simultaneously. The tree loads items and their workflow states from the Sitecore authoring GraphQL API, displaying each item's name, current workflow state, and language version in a clean, well-organized tree view with expandable/collapsible nodes. Users can filter the tree by template type, workflow state, or language to quickly locate relevant items, and a 'Select All Children' option enables rapid bulk selection of entire branches. Once items are selected, a prominent action panel at the bottom presents a dropdown of available workflow commands (e.g., Approve, Reject, Submit for Review) and an optional comment field, allowing the user to execute the chosen workflow transition across all selected items in a single operation. The panel provides real-time progress feedback during execution, showing success or failure status per item with clear visual indicators such as color-coded icons, and a summary report upon completion detailing how many items were transitioned successfully versus any that encountered errors.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Create the app in Sitecore App Studio:
   - Go to [Sitecore App Studio](https://portal.sitecorecloud.io/app-studio)
   - Choose `Custom app`
   - App name: `Bulk Workflow Manager`

4. Open the app configuration:
   - After creating the app, App Studio redirects you to the new app entry.
   - Open that app entry any time you need to update configuration.

5. Configure the extension point:
   - Select `Page Context Panel`
   - Install the app, then open a page in the Pages editor and find the app in the context panel.

6. Configure API access:
   - SitecoreAI APIs: `Select`
   - AI skills APIs: `Leave off`

7. Configure app permissions:
   - Pop-ups: `Select`
   - Copy to clipboard: `Select`
   - Read from clipboard: `Leave off`

8. Paste the deployment URL:
   - Use `http://localhost:3000` for local development or your deployed Vercel URL in production.

9. Upload the app logo:
   - Upload one square JPG, PNG, or SVG logo file.
   - Maximum size: 4MB.

10. Activate and install:
   - Click `Activate`
   - Return to App Studio and install the app to the desired environment
   - Install the app, then open a page in the Pages editor and find the app in the context panel.

11. Direct-open behavior:
   - If you open the deployed URL in a regular browser before installing the app in Sitecore, the generated app shows an in-app setup guide.
   - Use that screen to confirm the deployment URL, app name, and App Studio selections.
